# K7 documentation

**Canonical user docs** for K7 (CLI, API, Python SDK). Edit here only — this repo is the source of truth for the published site.

Mintlify site: run `mint dev` from the repository root (`~/docs`) where `docs.json` lives.

See the [root README](../README.md) for local preview and publishing.

## Publishing changes

Install our GitHub app from your [dashboard](https://dashboard.mintlify.com/settings/organization/github-app) to propagate changes from your repo to your deployment. Changes are deployed to production automatically after pushing to the default branch.

## Need help?

### Troubleshooting

- If your dev environment isn't running: Run `mint update` to ensure you have the most recent version of the CLI.
- If a page loads as a 404: Make sure you are running in a folder with a valid `docs.json`.
